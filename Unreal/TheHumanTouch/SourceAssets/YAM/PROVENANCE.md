The URDF and assets directory are unmodified upstream copies. Unreal meshes are derived by baking URDF visual origins and converting metres to centimetres; the OBJ importer converts handedness. No upstream controller code is executed. The selected standard YAM/gripper revision is provisional pending physical-station confirmation. See docs/dreamlabs-yam.md at repository root.
