## Optional brand-kit files

Google Drive is the source of truth for brand assets.

- Save new concepts, variations, and work in progress to [brand-kit-scratchpad](https://drive.google.com/drive/folders/1n4_CN9VJKYQcIOZmweIlhqgqyUfCq3BG).
- Use [brand-kit-final](https://drive.google.com/drive/folders/182y7Nq8LiD52ZSxj1PyLPU5zeF1fEcc_) for presentation-ready assets. Copy selected work here from the scratchpad. Emmy’s references are under `emmy/` and the brand guide is under `identity/`.

For the social renderer or Imagegen reference manifest, download the current Drive folders into the repository root under those same names. Git ignores both local folders. Upload new work to the appropriate Drive folder so the next thread can pick it up.
