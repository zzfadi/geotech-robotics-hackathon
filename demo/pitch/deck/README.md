# Stage presentation

Open **The Human Touch — Stage.key** for the native Keynote presentation. The PPTX is an editable interchange copy. The PDF shows Keynote’s rendered pages; movie slides show a still. The [slide contact sheet](slide-contact-sheet.jpg) shows the complete sequence.

Slides 1–13 form the three-minute pitch. Stop on the QR card. Slides 14–15 are for questions or an expanded finals presentation. Read the [timed outline](outline.md) or enable **View → Show Presenter Notes** in Keynote. All five exhibit movies are embedded in the document. The separate [31-second sequence](../films/higgsfield/museum-sequence.mp4) is available for standalone playback.

Slide 3 is the live performance cue. After feature lock, rehearse it with the real station and keep the actual recorded backup available offline. Slides 4–8 use concept imagery. The measured results on slide 10 refer to the runs described in its notes.

Baskerville sets the primary titles and figures; Avenir Next sets the supporting copy. The layouts alternate between full-frame art, large type and an editorial split. The double gilt edge is confined to the museum works.
